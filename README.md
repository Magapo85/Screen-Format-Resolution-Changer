# Screen-Format-Resolution-Changer

A quick and easy way to change the format resolution of your computer's main screen between 16/9 and 4/3.

Compile this cpp code and run the .exe file using the following three methods :
1) Open ResChange.exe to see and use the UI
2) In the terminal or command prompt to set >720p (16/9) => ResChange.exe 16/9
3) In the terminal or command prompt to set 480p (4/3) => ResChange.exe 4/3


Test on Windows environment
